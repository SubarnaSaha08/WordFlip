# WordFlip

A simple, elegant flashcard web app for learning vocabulary from a CSV file.  
Load your own word list, flip cards, and mark whether you knew the word — the app tracks your progress visually.

---

## 🚀 Features

- **CSV Upload Support**  
  Import any `.csv` file containing words and their meanings.

- **Interactive Flashcards**  
  Click to flip between *word* and *meaning*.

- **Progress Tracking**  
  Mark each word as **Known ✓** or **Unknown ✗**.

- **Keyboard Shortcuts**
  - **Space** → Flip the card  
  - **Enter** → Mark as *Known* (when flipped)  
  - **Right Arrow** → Mark as *Unknown* (when flipped)

- **Word List Panel**  
  View all words, their status, and select any word instantly.

- **No Backend Required**  
  Fully static — works on GitHub Pages.

---

## 📁 CSV Format

Your CSV should include **two columns** in the format:

_word, meaning_

- The **first value** is the word  
- Everything after the first comma is treated as the meaning

---

## 🛠️ How to Use

1. Open the app in your browser.
2. Click **Load CSV** and select your file.
3. Pick a word in the left panel.
4. Flip the flashcard, study, and mark your progress.
